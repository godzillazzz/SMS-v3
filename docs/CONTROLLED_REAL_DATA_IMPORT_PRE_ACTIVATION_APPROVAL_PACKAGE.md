## 2. Operational Scope, Stop Conditions & Allowed Actions
- **Controlled Import Purpose**: Populating SMS v3 database with authorized employee records under strict audit controls.
- **Exclusions**: Uncertified source files, contractor data, external user accounts, or active user credentials.
- **Stop Conditions**: Missing privacy certificate, unassigned rollback owner, schema mismatch, or unencrypted transport halts import execution immediately.
- **Allowed Next Actions**: Authorizes submission to Executive Steering Committee for Go/No-Go evaluation (`CONTROLLED-IMPORT-GO-NO-GO-REF-PLACEHOLDER`).
- **Prohibited Next Actions**: No real data import, no production database population, no user account activation.
