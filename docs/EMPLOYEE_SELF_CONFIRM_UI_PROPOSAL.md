# PROPOSAL — พนักงานยื่นยันการปฏิบัติงานด้วยตัวเอง (UI path)

**สถานะ:** ข้อเสนอ (ยังไม่เริ่ม implement) · ที่มา: ปิดช่องว่างหลังงาน RBAC 18 ต.ค. 2569
**ข้อเท็จจริง:** backend พร้อมแล้ว — `VIEWER` ที่ผูก employee สร้างคำขอ `CONFIRM_WORK_PERFORMED` เฉพาะกะตัวเองภายใน 7 วันได้ (มีเทสต์ + mutation proof) · **แต่ไม่มีทางเข้าใน UI**

## ทางเลือก

| # | แนวทาง | ข้อดี | ข้อเสีย | ประมาณงาน |
|---|---|---|---|---|
| **A** ⭐ | เพิ่มการ์ด/ปุ่ม "ยืนยันการปฏิบัติงาน" ในหน้า **`attendanceHistory`** (PWA ประวัติลงเวลาของพนักงาน — มีอยู่แล้ว: `AttendanceHistoryPwaPage`) | พนักงานใช้หน้านี้อยู่แล้ว · ข้อมูลกะของตัวเองอยู่ในมือ · ไม่ต้องเปิด console ผู้บริหาร | ต้องเพิ่ม UI + เรียก API 2 ครั้ง (list own shifts → createDraft → submit) | กลาง (1 รอบงาน) |
| B | เปิดให้ `VIEWER` เข้า `attendanceSupervisor` | แก้ routing บรรทัดเดียว | เป็นหน้า console ของผู้บริหาร (ตารางทั้งแผนก/ตัวกรอง/ปุ่มอื่น) — เสี่ยงสับสนและเสี่ยงเปิดข้อมูลเกินจำเป็น | ต่ำ แต่ความเสี่ยงสูง |
| C | สร้างหน้าใหม่ "ยืนยันเวลาของฉัน" | แยกชัดเจน | ต้องสร้าง route/menu/เทสต์ใหม่ทั้งหมด + เพิ่มเมนูให้ VIEWER | สูง |

## ขอบเขตที่เสนอ (ถ้าเลือก A)

1. **หน้า `attendanceHistory`**: แสดงเฉพาะกะของตัวเองย้อนหลัง ≤ 7 วัน ที่ยังไม่มีคำขอ → ปุ่ม "ยืนยันการปฏิบัติงาน"
2. **Flow**: กดปุ่ม → กรอกเวลาเข้า/ออก (prefill จากข้อมูลจริงถ้ามี) + เหตุผล (≥5 ตัวอักษร) → สร้างคำขอ (DRAFT) → ส่ง (`submit`) → แสดงสถานะ "รออนุมัติ"
3. **Guard ที่ต้องคงไว้**: ส่งได้เฉพาะกะของตัวเอง · เกิน 7 วันไม่ได้ (backend บังคับ) · ส่งแล้วแก้อะไรไม่ได้จนกว่าจะถูกส่งกลับ
4. **ไม่แตะ**: `attendanceSupervisor` (คงเป็น console ผู้บริหาร) · `assertAdmin` · approval = ADMIN เท่านั้น
5. **เทสต์ที่ต้องมี**: unit (query/สร้าง payload) · component (แสดง/ซ่อนปุ่มตามเงื่อนไข 7 วัน + มีคำขอแล้ว) · HTTP contract (createDraft/submit ของ VIEWER own vs other → 201/403)

## เกณฑ์ปิดงาน
- พนักงาน (VIEWER+ผูก employee) ยื่นยันของตัวเองได้จากหน้าจอจริง (ทดสอบบน Preview/CI harness)
- ไม่มีปุ่มสำหรับกะของคนอื่น · ไม่มีปุ่มอนุมัติ
- CI เขียว + SENTINEL review

## ความเสี่ยง/สิ่งที่ต้องตัดสิน
- **ต้องยืนยัน:** พนักงานควรเห็น "เวลาเข้า/ออกที่ระบบบันทึกไว้" หรือกรอกเองทั้งหมด (ถ้ากรอกเอง ต้องมีหลักฐานประกอบ?)
- **ต้องยืนยัน:** ต้องให้หัวหน้างานเห็นคำขอที่พนักงานยื่นหรือไม่ (ตอนนี้ supervisor เห็นเฉพาะแผนกของตัวเอง อ่านได้)
