SESSION SECURITY IMPLEMENTED
  Login creates a cryptographically random refresh token and stores only its
  SHA-256 hash. Refresh tokens rotate on every successful use. Reuse of a
  rotated/revoked token revokes all user sessions and increments tokenVersion.
  Logout revokes the supplied session; logout-all revokes all sessions and also
  invalidates access tokens through tokenVersion. Tokens and secrets are not
  included in audit records.
